# 黑板的樣式指南（分節模式 `beat.board`，v2）

寫黑板的人照這一份；格式在 `tools/content/course_v2/SCHEMA.md`「黑板」，流程在 `docs/board-authoring-brief.md`。
畫面在 `src/course_board.js`＋`src/course_board_layout.js`，版面由 `tools/lint_board_layout.js` 在真的 Chrome 裡量。

## 一句話

**一次只講一件事，講到哪、亮到哪。** 黑板不是把 `show` 再抄一次，是讓眼睛跟著旁白走：
式子寫上去 → 念到那個詞的那一刻，那一項被圈起來／變色 → 下一句開始，舊的記號安靜地收掉。

學的是 3Blue1Brown／Manim 的板書：克制、留白、顏色有固定的意思、動作是 ease-in-out（沒有等速、沒有彈跳）、
同一個項在式子變形時「滑」到新位置（不是消失再出現）。

## 顏色：一種顏色一個角色（整節不變）

| 顏色 | 角色 | 例子 |
|---|---|---|
| 粉筆白／墨黑（預設） | 一般的字 | 大部分的式子 |
| `blue` | 第一個主角：裡層、輸入、上限、被代進去的東西 | 連鎖律的 $g(x)$、FTC 的上限 $x$ |
| `violet` | 第二個主角：外層、累積函數 | 連鎖律的 $f'$、$A(x)$ |
| `gold`（記號的預設） | 「現在講的是這個」 | 圈、底線、`focus` |
| `green` | 結果、結論（框起來的答案） | $\frac{3}{4}$、「證完」 |
| `red`（劃掉的預設） | 錯的、不能用的、警告 | 劃掉的 $e^{2x}$、「可能是 0」 |

- 角色顏色用 `tint`（`{ "i": "blue" }`）掛在**項**上，不是整行：整節裡同一個 id 一直是那個顏色（變形、飛過去都帶著）。
- 一節最多兩個角色色（blue＋violet），再加 gold／green／red 三個功能色。不要為了漂亮換顏色。
- 整行上色（`color`）只用在「這一行本身就是結論或警告」：`green` 的最後答案、`red` 的「直覺，不是證明」。
- 兩個主題都量過：淺色板 #f7f5ee 上字 14.2:1、五個顏色 5.8–6.8:1；深色板 #17221e 上字 14.0:1、顏色 8.3–10.7:1（lint 擋 < 4.5）。

## 字與大小

- 板上的式子 20px（手機）／21px（平板）／24px（桌機）；KaTeX 一律 `\displaystyle`，跟課文同一套字型。中文 0.95em。
- **最小 16px**（360px 寬的手機也一樣）：太寬先縮（最多縮到 0.9 倍），再在單位之間換行（最外層的 `=`、`\le`… 前面、中文標點後面），
  換行的下一列以關係符號開頭時對齊到第一列的關係符號底下。還是放不下 → lint 擋（字 < 16px），把那一行拆成兩行寫。
- 標籤 13.5px、粗 650、跟記號同色，≤ 8 個字。
- 相鄰幾行都是「純式子而且有關係符號」時，整節用同一條 `=`（或 `\le`…）對齊；`⇒` 開頭的行不對齊（那是新的一句）。

## 版面：不會疊

- 一節一塊板，**高度在這一節開始時就定好**（這一節最滿的那一刻），之後不長高也不縮，下面的字不會被推來推去。
- 一行一列由上往下排，行距 0.75em；板上同時最多 4 行（一張圖算 2 行），最高不超過畫面高度的 55%（lint 量）。
- 標籤自動找位置：先試那一項（或那個記號）的正下方，再左右挪、上面、旁邊、第二條；碰到任何一個字、記號、箭頭、別的標籤、板邊就換。
  每個位置都放不下 → 在那一行底下讓出一條標籤的空間（整節的版面跟著重排，一開始就留好，不會中途跳）。
- 箭頭是一條二次曲線，試十幾種彎法，挑不穿過字、不出板、最短的；接在被圈的項的圈外面。
- 記號（圈、框）離旁邊的字留 ≥ 2px；貼太近的項（上標、括號旁邊的一個字母）不要圈，改用 `focus`（只變色）或 `underline`。

## 動作與時間

- 每一個動作都在旁白**念到某個詞**的那一刻開始：`"on": "外層"`（say 裡的字；重複的寫 `"外層#2"`）。
  時間來自錄音本身（逐字時間點），所以 1×／1.25×／1.5×、暫停、拖、網路卡住都對得上。
- 一句的第一個動作可以不寫 `on`（從這一句開頭開始）；之後的動作都要錨在念到的詞上（驗證器擋）。
- 長度是固定的「自然長度」：寫一行約 0.5–1.3 秒（看字數）、變形 1 秒、圈 0.65 秒、箭頭 0.8 秒；
  兩個錨點太近，前一個會被壓短（最短 0.22 秒）——錨點之間至少隔兩三個字。
- 寫：從左到右的軟邊遮罩露出來（不是一個字一個字跳出來）。變形：對得上 id 的項滑過去（同一行裡橫著搬會走一道往上的弧，不壓過別的字），
  舊的其他部分先淡出，新的再淡入。前幾行已經有的項在新的一行裡出現：複製一份從那裡飛下來。
- 記號：線條用 ease 一筆畫完，標籤在後半段淡入、往上浮 4px；被圈的項跟著變成記號的顏色。
- **記號只活一句**：下一句一開始淡出（0.32 秒）；它掛的那一行被變形、擦掉、搬動時，跟著那個動作淡出。要一直看得到的東西寫成式子，不要靠記號。
- 沒開旁白：同一張時間表跑在虛擬時間上（每個字約 0.17 秒）；點一下＝這一句直接畫完、下一句開始。reduced-motion：直接畫好。

## 什麼時候擦

- 換一個新的例子、新的式子家族 → 這一句第一個動作 `clear`。
- 推導往下長、上面兩行已經沒在用 → `keep`（留最後 n 行，留下的往上滑）。
- 不要擦了又馬上寫回一樣的東西；不要在一句裡 `clear` 兩次。

## 「為什麼」與小測：不要先畫出答案

- 證明節有 `why` 的句子：問著的時候只畫「這一步得到什麼」（錨在問句 `why.say` 的詞上），
  答案（用到的假設、理由）標 `"why": true`，答了或按「直接看」才畫（錨在 `say` 的詞上）。
- 每一節結尾的小測／預測：黑板上不能出現選項的答案（例如題目問 $F'(x)$，板上就不寫 $\cos(x^2)$）。

## 一句裡放什麼

- 1–5 個動作；一句只有一個重點記號最好，最多兩三個（連鎖律公式那一句：外層、原封不動、裡層三個是上限）。
- 黑板寫的是式子與很短的字；長的說明留在 `note`（黑板底下）與旁白。
- 板上的字、標籤、數字都要在課文裡出現過（驗證器的數字規則照舊）。

## v1 的問題（docs/report/course-review/screens/board-v1/，2026-10-12 的截圖）

看得到的毛病，v2 每一條都有對策（括號裡）：

1. **記號疊在字上**：$f'$ 的框蓋到右邊的「(」與左邊的「=」；圈 $du$ 的紅圈壓過分數線、跟另一個圈疊在一起
   （chain-rule-3-end）；框 $g$ 的框劃過「=」、圈 $\frac12$ 的圈切到「≤」（dominated-convergence-2-end）。
   （記號的外框照到旁邊的字的距離算，lint 量每一個記號 vs 每一個字。）
2. **標籤擠成一串、壓到東西**：「外層 原封不動」黏在一起看不出誰是誰；「像約分：直覺」壓在圈上。（標籤避讓、彼此至少 6px。）
3. **跑出板外**：最後一節的圈比板寬，右邊被切掉（chain-rule-7-end）；第一行貼著板邊。（記號與箭頭的範圍也算進出板檢查；左右留 16px。）
4. **上一句的記號一直留著**：舊的圈在新的式子旁邊，分不清現在講哪一個。（記號只活一句。）
5. **顏色沒有意思**：同一個金棕色一下是外層、一下是裡層、一下是答案；深色板上紅圈太搶。（角色色固定，記號預設 gold。）
6. **粉筆圈手繪感太重**：歪的橢圓、粗線、每個圈形狀都不一樣，看起來潦草。（超橢圓貼著項，起點左上、多畫一點收尾；線寬 2.1。）
7. **板一直長高**：每寫一行，下面的句子被往下推，捲動要一直重對（還修過一次「打字時被捲走」的 bug）。（一節一個固定高度。）
8. **時間不對**：動作平均分掉一句的時間，圈常常在念到那個詞之前或之後一兩秒出現；1.5× 與暫停後會越差越多。（錨在詞上、跟著 currentTime。）
9. **一個字一個字跳出來、粉筆頭的小點**：有點吵。（軟邊遮罩一次滑過去。）

## 不要做（anti-patterns）

- 圈一個上標、一個運算符號旁邊的字母（壓到旁邊）→ 用 `focus` 或 `underline`。
- 一句裡三個以上帶標籤的記號；兩個標籤講同一件事。
- 用顏色當裝飾（整行 gold 只為了好看）；同一個角色在不同句子換顏色。
- 箭頭連兩個在同一行、緊挨著的項（彎不出去）→ 用文字或 `focus`。
- 一行寫超過 32 個看得到的字；一句裡塞兩個推導步驟（拆成兩句）。
- `on` 錨在句子最後兩三個字（動作還沒畫完，下一句就開始了）。
