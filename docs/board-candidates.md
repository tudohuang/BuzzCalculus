# 哪些課、哪幾節要畫黑板（fan-out 清單）

產生方式：讀 317 課每一節每一句的 `show`，看「能不能在板上寫出一連串式子的變化」
（腳本的判斷照下面的準則；排序 = 值不值得 × 看的人多不多）。這是起點不是判決：寫課的人打開那一節，照準則再判一次，不值得就跳過、寫在回報裡。

## 準則：值得畫的

1. **推導**：相鄰兩三句都是式子，一句是上一句變形來的（約分、代入、整理、配方、換元、分部積分的兩步）。黑板的價值最大：`transform` 讓同一個項滑過去，學生看得到「哪一塊變成哪一塊」。
2. **證明節**（`proof: true`）：一步一句，式子一行一行往下長；`why: true` 的動作剛好放「這一步的理由」（答了才畫）。
3. **多步的計算**：一題範例拆成 3–5 句（先拆外層裡層、再各自微分、再相乘、再代點），每一句一行，最後框答案。
4. **要指著式子的一部分講**：「這一項是外層」「上限會動」「這裡會是 0」—— 圈、底線、`focus` 正好落在念到那個詞的時候。
5. **圖形直覺而課裡沒有 widget**：一張小圖（`plot`）＋一兩行式子（例如「夾在 m、M 之間」）。已經有 widget 的節（`fig`）通常不用再畫圖。

## 準則：不值得畫的

- 純文字的節（定義、動機、歷史、「為什麼要學這個」）：黑板只會把 `show` 抄一次，還把字變小。
- 一節只有一個式子：寫上去之後整節都在念那一行，板上沒有變化。
- 已經有 widget 在動、黑板會跟它搶注意力的節。
- 小測／預測之前一句：不要在板上先寫出答案。
- 一句話裡要寫的式子超過 32 個看得到的字、又拆不開（例如很長的泰勒展開）：先改 `show`，或跳過。

## 份量（腳本估的，寫的時候以實際為準）

每一課最多挑 3 節（分數最高的），一節要畫就整節的句子都畫（板是一節一塊，中間斷掉很怪）。
