# 全站 trailer：分鏡表

一支約 50 秒、節奏快的全站介紹片（課程區另有一支慢的：`tools/course_film/`）。
目標是「帥、流暢、讓人想點」：拍點剪接、橫搖轉場、大字逐字彈出、真實介面在 3D 裡推近。

## 拍法（查過的產品宣傳片做法，落到這支片上）

| 做法 | 意思 | 在這支片的哪裡 |
|---|---|---|
| 前 2–3 秒的鉤子 | 社群上滑過去之前要先抓住人 | 片頭四個式子跟著拍子砸下來，第五拍才出標題 |
| 剪在拍子上 | 切點對齊音樂，畫面有節奏 | 每一幕的長度都是整數拍（120 BPM，一拍 0.5 秒） |
| 橫搖轉場（whip pan） | 快速橫搖＋動態模糊接到下一幕；配一聲 whoosh | 大部分轉場：出場與進場用同一條曲線，像一次橫搖 |
| 動態字（kinetic typography） | 字的動作要幫意思，不是每個字都加特效 | 標題逐字從下面彈上來、關鍵詞金色；一幕一句 |
| 真實介面＋鏡頭推近 | 用產品真的畫面，鏡頭帶眼睛看重點 | 作答／證明／課程：左邊字、右邊視窗，3D 傾斜進場後推近到輸入框、回饋 |
| 分格同時動（bento） | 一個畫面放幾個功能同時動，表達「很多」 | 「不只選擇題」：切線、臨界點、作圖、ε-δ 四格一拍一格彈出 |
| 快切蒙太奇 | 一拍一個畫面，表達累積 | 每日一題、弱點／模擬／挑戰、錯題本、證明題庫、自己挑題 |
| 建立→高潮→收 | 音樂段落跟著內容：鋪底→進鼓→drop→斷開→收 | 「不只選擇題」上升音進 drop；數字卡前小鼓滾奏、斷開；片尾大和弦 |
| 結尾 CTA | 最後留網址 | 商標＋網址＋桌機與手機的畫面 |

## 做法與重做

- 素材：`node tools/site_trailer/record.js [--only ok,wrong,slope,tap,interval,eps,sketch,proof,home,stills]`
  - 互動鏡頭是「慢動作錄」：頁面裡的時間（setTimeout、performance.now、Date.now、rAF、CSS 動畫）放慢 8 倍，DSF 2 一直截圖，時間戳除以 8 換回真實速度 → 一秒約 40 格、2360×1640。
  - 不用 screencast（只給 CSS 像素，要清楚得開 zoom 2，但 zoom 會讓點擊座標對不上；而且只有一秒 7–13 格）。
  - 課程鏡頭直接用 `docs/trailer/course-film/raw` 的素材（先跑過 course_film/record.js）。
- 看版面：`node tools/site_trailer/render.js --preview`
- 出片：`node tools/site_trailer/render.js`（1080p60，約 15 分鐘）；`--fps 30` 快一半；`--audio` 只重做配樂
- 改字、改鏡頭只動 `scenes.js`；素材與成片在 `docs/trailer/site/`（不進版控）
