# 課程區短片：分鏡表

一支約 90 秒、偏文學感的課程介紹片。主角是課程本身：板書跟著旁白一句一句出現，所以片子的聲音就用課程裡真的旁白，不另外配旁白。

## 拍法（查過的電影語彙，落到這支片上）

| 手法 | 意思 | 在這支片的哪裡 |
|---|---|---|
| 三幕結構 | 紀錄片常用：第一幕是前提與脈絡，第二幕調查最長，第三幕收束最短 | 一、錯先寫出來 → 二、一課是怎麼做的 → 三、整條路 |
| J-cut | 下一鏡的聲音先進、畫面後到 | 片頭黑畫面先聽到「裡面不是單純的 x」，畫面才淡入 |
| L-cut | 上一鏡的聲音延到下一鏡 | 「錯」那句旁白的尾巴蓋到字卡上 |
| 建立鏡頭（establishing shot） | 交代整個場景與位置 | 213 課的地圖，大遠景慢慢搖過 |
| 大特寫（ECU）與跟焦（rack focus） | 只拍一個細節；焦點從模糊拉到清楚，帶觀眾看該看的地方 | 開場推到紙上的第一行字、焦點從糊拉清 |
| 慢推（push-in） | 鏡頭慢慢靠近，表示「這裡重要」 | 圓圈、箭頭、「錯」字出現時慢推 |
| 拉遠揭示（pull-back reveal） | 從細節拉遠，才看出全貌 | 寫了筆記的那一頁 → 攤開整課 |
| 匹配剪接（match cut） | 前後兩鏡在同一個位置有同一個東西 | 自己寫的「×2」→ 攤開的板子上同一個「×2」 |
| 搖鏡（tilt） | 鏡頭上下搖 | 攤開的整面往下搖 |
| 蒙太奇 | 一串短鏡頭表達累積 | 四課攤開的整面，一鏡一課 |

文學感的處理：寬銀幕黑邊（2.39:1）、楷體字卡＋大量留白、字一個一個「洇」出來（模糊收斂）、溶接取代硬切、獨奏鋼琴 66 BPM、輕微底片顆粒與暗角、數字用句子念出來而不是跳動的計數器。

## 重做

- 素材：`node tools/course_film/record.js [--only a-wrong,b-arrow]`（DSF 3，約 2.4 格／秒，全部約 20 分鐘）
- 看版面：`node tools/course_film/render.js --preview`
- 出片：`node tools/course_film/render.js`（1080p）或 `--dsf 2`（4K 母帶＋1080p）
- 改字、改鏡頭只動 `scenes.js`；素材與成片在 `docs/trailer/course-film/`（不進版控）
